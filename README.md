# Neccessary Files

For some scripts it is neccessary to download the URLhaus and Malware Bazaar FULL CSV database files.

## Future Work

We want to make a small project which creates new datasets to our current features. Furthermore, we want to add a ground truth dataset. We also want to create a better benign dataset.
